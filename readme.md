# Calculadora Simple

## Descripción

Este proyecto fue desarrollado como parte de una actividad de trabajo colaborativo utilizando Git y GitHub.

La aplicación consiste en una calculadora simple capaz de realizar operaciones matemáticas básicas entre dos números.


## Funcionalidades

- Suma
- Resta
- Multiplicación
- División
- Visualización dinámica de resultados

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Git
- GitHub
